# ninan13.github.io

My custom personal homepage and website hosted on **GitHub Pages**.

🔗 **Live Site:** [https://ninan13.github.io](https://ninan13.github.io)

---

## 📁 Project Structure

```text
ninan13.github.io/
├── index.html      # Main HTML document
├── style.css       # Clean styling with light/dark mode support
└── README.md       # Project documentation
```

---

## 🚀 Local Preview

You can open `index.html` directly in your browser, or run a simple local web server:

```bash
# Using Python
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your web browser.

---

## 🛠️ Customization

- **Add Quick Links**: Edit the `<section class="links-grid">` in `index.html` to add your favorite bookmarks or shortcuts.
- **Add Projects**: Update the `<section class="projects-grid">` to link to more of your repositories or demos.
- **Theme & Colors**: Modify the CSS variables at the top of `style.css` (`--bg`, `--surface`, `--accent`, etc.).
